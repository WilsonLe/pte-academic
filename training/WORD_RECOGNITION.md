# Independent word recognition in speaking review

For the separately paused training work, rejected candidate results and proposed
content/pronunciation/fluency responsibilities, see [speech assessment research](../docs/speech-assessment-research.md).
That proposal does not change the published runtime described below.

The operator explicitly requested recognition without reference text for all seven speaking types, and accepted the existing synthetic reference bank, labelled Reference pronunciation. Recognition, segmentation, sound grading and the optional prompt diff are distinct stages. No learner audio or derived text leaves the device.

Two frozen public Apache-2.0 recognizers are independently pinned by `recognition_model.py`. Sentence-length context uses `facebook/wav2vec2-large-960h-lv60-self` revision `54074b1c16f4de6a5ad59affb4caa8f2ea03a119`, exported to 241,236,684 bytes with symmetric block-32 weight-only INT4 MatMulNBits (RTN, accuracy_level=0). Activations, convolution and other operations remain float32; there is no fitting or activation calibration. Isolated context below 2 seconds and longer context above 45 seconds retain the exact original `facebook/wav2vec2-base-960h` revision `22aad52d435eb6dbaf354bdad9b0da84ce7d6156` encoder:189,043,500 bytes of float16 constant storage with float32 operations. Source weights and configuration files are verified before local loading; the long encoder reproduces the original published hash. Neither replaces the v3 phonetic model. Greedy character CTC supplies words, confidence and estimated boundaries from audio alone, without an added dictionary/language-model prior, prompt, hotwords or answer key. Controls establish compatibility, not human learner word-error validation; long responses retain the base recognizer's accuracy limitations. See [ADR-0001](../docs/adr/0001-use-a-compact-self-trained-audio-only-recognizer.md) and the [upstream LV-60 model card](https://huggingface.co/facebook/wav2vec2-large-960h-lv60-self).

A compact 124,082-word pronunciation dictionary contains locally generated US/GB eSpeak phonetic variants for CMUdict spellings and current fixed-question words. CMUdict vocabulary license is bundled. Australian and Indian sounds remain equally accepted by the unchanged v3 acoustic reference bank; dictionaries and the recognizer do not establish equal recognition accuracy across accents. Unsupported phonetics are omitted. Recognized words outside the dictionary, low recognizer confidence (<0.4), failed alignment or uncertain sound evidence receive no invented grade.

Recognition and phonetic grading both retain 20-second owned spans with one second of context on each side (at most 22 seconds), keeping recognised words by midpoint. Silent edges are trimmed with 200 ms of acoustic context. Sum the lengths of those trimmed windows: 2–45 seconds uses LV-60; isolated context below 2 seconds and greater context cost use the original base recognizer. This audio-only choice excludes long silent tails and separated short speech from the cost. The context floor preserves original isolated-word behavior after a native ice clip regressed under INT4; it does not inspect recognised text or claim improved short-answer accuracy. A large-only recognizer exceeded the unchanged 300 second worker deadline on continuous125 second speech; smaller windows and alternative quantization formats did not provide enough headroom. The final browser control completed continuous 125-second speech within the unchanged 300-second deadline, using the exact original base encoder and unchanged grader; sustained mixed-accent speech also passed the original coverage threshold. The recognition session is released before loading v3. Each word's interval selects phonetic encoder frames for dictionary-based local alignment and the unchanged trained sound projection/reference-bank comparison. Timestamps are estimates. Up to 125 seconds is accepted for open speaking tasks; legacy expected-text and isolated syllable calls retain their45 second limit. Cancellation, silence/noise and integrity checks remain in place. Difficult learner speech and human pronunciation validity remain evaluation gaps.

The independent result adds `recognition: {modelId, recognizerSha256?, recognizerRevision?, decoder?, windowSeconds?, words}` to the compatible pronunciation record. New results identify the selected encoder/upstream revision and `greedy-ctc-duration-v1` decoder with `windowSeconds:20`. Earlier `greedy-ctc-v1` and `greedy-ctc-adaptive-v1` records remain compatible. Older independent results remain readable and are not silently rescored. Each word has spelling, occurrence index, start/end, confidence and recognized/uncertain/unsupported state. Only the existing IndexedDB queue persists it. An upgrade stores its result separately as `speechAssessment` and leaves `pronunciation` intact; no transcript or grade enters the localStorage index. All speaking types use the same review owner and effort-only retry XP contract. The optional prompt edit-distance diff changes display only; it cannot alter recognised words, times or grades.

The bundled word-audio library derives 998 word entries from retained training examples (no held-out/test voice) and existing original review examples. Each clip retains source take/hash, synthesis/listening status, accent and estimated syllable bounds. Several available accents remain available as source references; the UI selects a matching label/count when possible. These are contextual word excerpts, not new standalone studio takes. Whole-word playback remains available for another pronunciation pattern, but a syllable reference is shown only when its pattern matches the learner’s scored labels. No new audio is synthesized and no paid request is made. The library is smaller than the phonetic dictionary: an absent reference recording is shown explicitly, with learner playback retained. Missing clips never silently substitute a prompt lookup, browser/OS voice or cloud provider. Human listening/learner pronunciation validation is pending; “gold standard” is not claimed.

Obtain both public checkpoints and their tokenizer/configuration files from the exact upstream revisions into an ignored local directory; verify the source SHAs specified in `recognition_model.py`. Raw source checkpoints are not shipped. For an encoder-only rebuild retaining existing pinned dictionary/reference derivatives, pass `--encoder-only` to `export_recognition.py`; it verifies all retained assets and does not require re-exporting word references.

The two exporters write pinned manifests to public and source, with complete hashes, source identities and exporter digests. Run them in that order. Browser controls stay in ignored `artifacts/word-recognition-export/` with distinct `control-` names; reference temporary PCM uses `reference-` names. Raw corpus, Python dependencies, source checkpoint files and credentials remain outside the publish artifact. The recognition pack includes both encoders plus the unchanged dictionary and reference audio; decoded and transfer sizes are pinned separately in its manifest; automatic preparation remains in the notification bell. Phonetic assets, runtime and references retain the verified scope-specific model cache, separate from the ordinary offline app bundle. Each recognition encoder uses an additional immutable cache namespace keyed by its decoded SHA; legacy encoder entries are copied only after complete hash verification and remain intact.

Rollback is reverting the recognition assets and integration; the unchanged v3 bank and original recordings are retained. Older readers ignore additive result fields. No model benchmark, synthetic classification statistic, transcript match or content diff is a validated learner pronunciation/fluency/exam score.

## Lossless browser transport and isolated retries

After regenerating the browser comparison and recognition packs, run `node scripts/pack-models.mjs`, then `npm run validate:comparison`. The packer shuffles binary byte pairs and uses gzip; JSON uses `.packed` sidecars to avoid static hosts applying HTTP gzip decoding automatically. Transport hashes and decoded hashes are both pinned. Decoded encoder hashes, model identity, head, bank and calibration remain unchanged; existing verified decoded caches remain reusable. `totalDownloadBytes` reports transfer size separately from `totalBytes`.

Word-reference index/audio files can be fetched and verified independently while automatic preparation continues in the header. Warm availability uses validated-file receipts; every inference/reference read checks the decoded SHA again. Corrupt reads remove their cache entry for a real notification retry.

Retries use word-local phonetics with compatible synthetic syllable clips, processed through the browser's native recording codec, trimmed and padded equally, with ±10 ms reference phases. The existing projection compares each phone against its nearest compatible reference, giving each accent equal validity. Every phone requires confidence >=0.03; incomplete/uncertain reference or learner alignment returns no numeric grade. These controls establish codec-path consistency and wrong-sound rejection for the bundled examples, not human pronunciation validity. Original session scoring and saved evidence do not change. No audio leaves the device.

Short-response chunks use the distinct `recognizer-lv60-int4-` prefix. Long responses retain the four original `recognizer-NN.bin` files, including their exact published compressed bytes, so older tabs can complete their downloads. Each encoder now has a cache namespace derived from its pinned encoder SHA; v3, references, runtime and legacy entries retain the existing model-cache identity. A compatible legacy entry is copied only after full decoded hash verification and is never deleted. Preparation rechecks receipts for every required file before reporting ready. Warm checks inspect receipts; actual inference reads still verify decoded SHA and evict corrupt entries for retry. All required preparation and retry UI remains in the header. Keep older caches and saved assessments intact; do not activate an app update during an attempt.
