# v3 browser sound-similarity export

The operator requested using accepted v3 in app grading and explicitly required automatic model download. Read Aloud and Repeat Sentence now invoke its trained sound-comparison projection, reference bank and common calibration on locally recorded speech. Whisper word match remains separate. All US/GB/AU/IN references remain equally valid. Stress assessment is not part of this browser score.

Original `model.pt` SHA-256: `2a8e9680e71c85d98f2adc8da725c56f21bd866340cf545916fdf5dff7389d1b`. No fitting, new corpus generation, paid request or fresh final-test selection occurred. `training/export_browser.py` exports the pinned acoustic encoder's exact layer-7 and complete observed CTC distribution, plus unchanged v3 projection/reference bank/calibration and exact US/GB candidates for supported original question texts. Curly apostrophes are normalized to straight contractions before authoring browser candidates, matching app text normalization; the historical Python training tokenizer/source is unchanged. Targets/accent IDs are never appended to projection features. Unsupported texts and uncertain syllables have no grade.

The first q8 encoder was rejected because a difficult AU syllable shifted by 21.45 points. The shipped encoder stores constants as float16 and casts to float32 operations; it is not q8 or native float16 arithmetic. Four Python ONNX development samples agreed with the original within 0.01 points. Actual Chrome/WASM checks across twelve existing four-accent development/wrong-target controls agreed within 0.02 points, with identical scored/uncertain coverage. This is numerical compatibility evidence, not human pronunciation accuracy or a hardware-wide performance guarantee. The accepted AU sample still scores 20/21 syllables.

Pack: 654,068,930 bytes (~624 MiB), plus ~14 MiB local speech runtime. Encoder graph 632,158,340 bytes is split into thirteen <=48 MiB parts for Git storage, reconstructed only inside the worker. Metadata is 21,910,590 bytes; it contains learned weights/banks and supported phonetic scripts, not raw training audio. `public/models/blended-english-v3/manifest.json` and its identical application manifest bind every part/metadata hash, encoder revision, original checkpoint and exporter identity. Apache-2.0 encoder attribution/license and ONNX Runtime license are beside the pack. Raw corpus/features/environments/private credentials remain excluded from Git/build.

On startup the required pack/runtime downloads automatically with progress, integrity checks and retry. Grading waits for readiness; no optional toggle, skip or word-match fallback. Preparation/error status occupies a reserved strip below the app header, keeping practice/history navigation available. Cache keys include origin/base scope and export version; ordinary service-worker updates/history clearing retain the model cache. Missing/corrupt assets detected during scoring invalidate readiness and expose download retry without a page reload. The ordinary offline pack excludes large weight files. Recording input is local-only, at most 45 seconds, with serialized worker ownership, cancellation and five-minute timeout. Spectral-flatness preflight rejects silence/broadband noise (browser uses a zero-padded FFT window; Python uses its original FFT); the per-syllable confidence gate remains 0.03.

Results preserve original checkpoint SHA, export identity, accents, times/confidence/status and syllable similarity. Only the existing IndexedDB queue saves them, refusing cleared/pruned/non-recorded attempts; no localStorage result/XP writes. The model score is a 0–100 synthetic-reference similarity index, not percent correct, intelligibility, fluency, proficiency or an exam score. AU/IN dictionaries remain US/GB candidate based; human validity/listening remains unproven. Low-memory devices can fail to initialize this large encoder; that is an error state retaining the recording, never a numeric substitute.

Rebuild and validation commands are in `training/README.md` and `training/RESUME.md`. Browser parity fixtures are generated by `training/browser_cases.py` from retained local development recordings and remain ignored. `npm run test:comparison:browser` exercises actual inference, required download/failure/retry, local persistence, cancellation, fresh-document offline inference and unsupported-worker recovery. Full merge evidence and exact reviewed/resulting revisions belong to the PR review record. Historical v3 training evidence files remain unchanged.
