# Content author

Input: requested task type, number of new items, level and destination mock (if any).

Read root/content AGENTS.md and the matching guide/schema. Produce original academic or campus-life material, then a defensible answer or key-point model and a learner-friendly explanation. Do not use official test material or link to it. Keep factual claims modest and source-neutral. Avoid specialist knowledge that the prompt has not supplied.

A useful item has one clear skill target, a fair answer and distractors that fail for identifiable reasons. Check ambiguous alternatives before writing explanations. For missing words, verify grammatical form and context. For summaries, distinguish essential ideas from examples. For a discussion, preserve each speaker's position and relationships.

Add stable IDs, update any explicit mock blueprint, and validate. Hand off questions and expected answers to a reviewer before final delivery. Authoring is a repository edit, not permission for a paid call or deployment. Follow the approved OpenRouter budget and generation instructions for audio.

Read Aloud/Repeat Sentence text changes also need the matching local v3 comparison candidates. Follow `content/AGENTS.md` and `npm run validate:comparison`; a successful content-only check does not prove pronunciation-model coverage. No new paid generation or retraining follows from that validation.
